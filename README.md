# Калькулятор

**Розрахунково-графічна робота з ООП**

## Мета проєкту

Створити програму-калькулятор мовою Python.

## Основні можливості

- додавання
- віднімання
- множення
- ділення
- зміна знака числа
- обернене число *1/X*
- очищення введених даних
- видалення останнього символу
- десяткова система числення
- двійкова система числення
- шістнадцяткова система числення
